# Building Energy Consumption Segmentation

This project analyzes building energy consumption patterns using machine learning techniques.

## Technologies
- Python
- Scikit-learn
- Pandas
- NumPy

## Methods Used
- PCA (Dimensionality Reduction)
- K-Means Clustering

## Dataset
Energy consumption dataset of 1455 buildings.

## Results
Achieved silhouette score of 0.53 indicating effective clustering.
